# Web Speech API dan dau, Cloudflare Whisper bao dam tuong lai

Doi voi mot ung dung flashcard static tren GitHub Pages, noi nguoi dung doc cum tu tieng Anh ngan (1-5 tu), **Web Speech API la lua chon tot nhat de bat dau** -- zero setup, zero cost, do tre thap, va do chinh xac tot cho cum tu ngan tieng Anh. Tuy nhien, no chi hoat dong tot tren Chrome/Edge (Firefox khong ho tro, Safari khong on dinh tren iOS), va Chrome gui audio den server Google nen khong thuc su "offline". **Cloudflare Workers AI voi Whisper** la giai phap production tot nhat: free tier 10,000 neurons/ngay (~243 phut transcription), khong can credit card, Worker do ban viet nen khong lo CORS hay lo API key, va chat luong Whisper vuot troi Web Speech API. Neu can chay hoan toan local/offline, **transformers.js voi whisper-tiny.en** (~40MB download mot lan) la lua chon kha thi nhat -- xu ly cum tu ngan trong duoi 1 giay tren desktop, 1-3 giay tren mobile. Cac cloud API khac (Groq, Deepgram, Google Cloud, Azure) deu co free tier nhung yeu cau proxy backend va setup phuc tap hon ma khong mang lai loi the ro ret so voi Cloudflare Workers AI cho use case nay.

## Web Speech API: zero setup nhung gioi han browser la diem yeu lon

Web Speech API la giai phap don gian nhat voi chi **~10 dong JavaScript**, khong can backend, khong can API key, khong can tai model ([MDN Web Docs](https://developer.mozilla.org/en-US/docs/Web/API/SpeechRecognition)). Doi voi flashcard app, do tre rat thap -- ket qua tra ve trong **1-2 giay** sau khi nguoi dung noi xong. Timeout 60 giay cua Chrome hoan toan khong anh huong vi cum tu chi dai 1-5 giay ([Chromium Discussion](https://groups.google.com/a/chromium.org/g/chromium-html5/c/s2XhT-Y5qAc)).

Tuy nhien, van de lon nhat la **browser compatibility**. Firefox hoan toan khong ho tro Web Speech API recognition ([VocaFuse Blog](https://vocafuse.com/blog/web-speech-api-vs-cloud-apis/)). Safari desktop ho tro day du nhung iOS Safari thi "inconsistent, dac biet trong background tabs" ([VocaFuse Blog](https://vocafuse.com/blog/web-speech-api-vs-cloud-apis/)). Chrome/Edge la duy nhat on dinh, nhung audio duoc gui den server Google de xu ly -- nghia la day **khong phai giai phap local** ([MDN](https://developer.mozilla.org/en-US/docs/Web/API/SpeechRecognition)). Ngoai ra, Google co **rate limiting khong duoc document**, co the gay "unpredictable user experience" ([VocaFuse Blog](https://vocafuse.com/blog/web-speech-api-vs-cloud-apis/)). Doi voi flashcard, rate limiting it khi la van de vi nguoi dung chi noi tung cum ngan voi khoang nghi tu nhien giua cac the.

Ket luan: Web Speech API la lua chon ly tuong cho **MVP nhanh** khi target audience chu yeu dung Chrome/Edge. Setup chi mat vai phut va hoat dong ngay lap tuc. Nen dung lam primary voi fallback sang cloud API cho browser khong ho tro.

## Cloudflare Workers AI Whisper: giai phap production khong ton chi phi

Cloudflare Workers AI cung cap model `@cf/openai/whisper` voi **10,000 neurons mien phi moi ngay** (reset luc 00:00 UTC), khong can credit card, khong can waitlist ([Cloudflare Workers AI Pricing](https://developers.cloudflare.com/workers-ai/platform/pricing/index.md)). Model whisper co chi phi **41.14 neurons/phut audio**, nghia la free tier bao ~243 phut transcription moi ngay ([ToolFreebie](https://toolfreebie.com/cloudflare-workers-ai/)). Doi voi clip ngan 3-5 giay, moi request chi ton khoang **2-4 neurons**, nen 10,000 neurons du cho **hang ngan** lan nhan dien moi ngay. Mot session flashcard dien hinh voi 50 the, moi the 5 giay, chi tieu ~165 neurons -- chi 1.65% free quota.

Diem manh lon nhat cua Cloudflare Workers AI cho static site la **Worker chinh la backend cua ban**. Ban tu viet Worker (~20-30 dong code), tu set CORS headers, va khong bao gio lo API key ra browser. Khong can backend server rieng, khong can database -- chi can deploy Worker len Cloudflare (mien phi) va goi tu GitHub Pages. Do tre cho clip ngan khoang **1-3 giay** tong round-trip (bao gom network + inference) nho inference chay tren edge GPU gan nguoi dung ([Cloudflare Docs](https://developers.cloudflare.com/workers-ai/models/whisper-large-v3-turbo/)).

Ve audio format, Whisper tren Cloudflare chap nhan **WAV, MP3, MP4, M4A, OGG, FLAC, va WebM** ([Cloudflare Whisper docs](https://developers.cloudflare.com/workers-ai/models/whisper-large-v3-turbo/)). MediaRecorder trong browser xuat `audio/webm;codecs=opus` -- format nay hoat dong truc tiep voi Whisper ma **khong can convert**. Mot clip 5 giay o 128kbps chi khoang **40-80KB** ([Wikipedia Opus](https://en.wikipedia.org/wiki/Opus_(audio_format))), upload gan nhu ngay lap tuc ke ca tren mobile data.

## Groq va Deepgram: thay the manh nhung phuc tap hon

**Groq Whisper API** noi bat voi toc do inference cuc nhanh nho phan cung LPU chuyen dung, va free tier rong rai: **28,800 audio-seconds/ngay** (480 phut), 2,000 requests/ngay ([Groq Docs](https://console.groq.com/docs/speech-to-text)). Tuy nhien, Groq khong ho tro CORS va yeu cau API key trong header -- bat buoc phai co proxy. Neu da co Cloudflare Worker, ban co the route request qua Worker den Groq de tan dung toc do sub-second inference cua no. Nhung dieu nay them mot lop phuc tap ma khong thuc su can thiet khi Cloudflare Workers AI da du tot cho cum tu ngan.

**Deepgram** cung cap **$200 credit mien phi** (khong het han, khong can credit card), du cho ~25,000+ phut transcription ([Deepgram Pricing](https://deepgram.com/pricing)). Diem dac biet la Deepgram co **WebSocket API** co the goi truc tiep tu browser (WebSocket khong bi CORS restriction nhu HTTP) ([Deepgram Blog](https://deepgram.com/learn/live-transcription-mic-browser)). Tuy nhien, API key van lo trong browser dev tools. $200 credit la one-time, khong recurring -- khi het thi phai tra tien. Deepgram phu hop nhat cho real-time streaming nhung cho flashcard voi cum tu ngan, batch processing la du.

**Google Cloud Speech-to-Text** (60 phut/thang mien phi) va **Azure Speech** (5 gio/thang mien phi) deu yeu cau setup phuc tap (GCP/Azure account, billing, credentials) va proxy backend. Khong dang de xem xet khi cac giai phap don gian hon da du dap ung ([Google Cloud Pricing](https://cloud.google.com/speech-to-text/pricing)). **Hugging Face Inference API** giam free tier xuong chi **$0.10/thang** credit, hau nhu khong du cho bat ky so luong request nao co y nghia ([Klymentiev Blog](https://klymentiev.com/blog/huggingface-inference-api)).

## Chay Whisper truc tiep trong browser: offline hoan toan nhung co trade-off

Neu yeu cau **offline/privacy** la uu tien hang dau, **transformers.js voi model `Xenova/whisper-tiny.en`** la lua chon tot nhat. Model quantized chi ~40MB, download mot lan va cache trong browser (IndexedDB/Cache API) ([AssemblyAI Blog](https://www.assemblyai.com/blog/offline-speech-recognition-whisper-browser-node-js)). Sau lan tai dau, moi lan dung deu ngay lap tuc. Tren desktop, xu ly cum tu 1-5 tu trong **duoi 1 giay** via WASM. Tren mobile (Android Chrome), mat khoang **1-3 giay** -- chap nhan duoc cho flashcard ([OfflineTTS Guide](https://offlinetts.com/blog/browser-speech-recognition-whisper-comparison/)).

WASM la backend an toan nhat cho inference vi WebGPU con rat manh mun: **Safari hoan toan khong ho tro WebGPU**, Firefox chi experimental, va Linux Chrome can flag dac biet ([OfflineTTS Guide](https://offlinetts.com/blog/browser-speech-recognition-whisper-comparison/)). Thu vi la tren Apple Silicon Mac, WASM thuc te **nhanh hon WebGPU** cho Whisper (4.9s vs 9.6s cho 60s audio) ([GitHub Issue #894](https://github.com/huggingface/transformers.js/issues/894)). Can chay inference trong **Web Worker** de UI khong bi block.

Ngoai ra, **Vosk-browser** (hoac fork moi hon **Vosklet**, chi 614KB runtime) ho tro **streaming real-time** -- co the hien thi partial text khi nguoi dung dang noi ([GitHub Vosklet](https://github.com/msqr1/Vosklet)). Model tieng Anh cung ~40MB. Tuy nhien, community nho hon va documentation it hon transformers.js. **Sherpa-onnx** co nhieu tinh nang nhat (VAD, speaker ID, streaming) nhung model 80MB+ va setup phuc tap -- overkill cho flashcard ([GitHub sherpa-onnx](https://github.com/k2-fsa/sherpa-onnx)). **DeepSpeech va Coqui STT** da ngung phat trien hoan toan -- khong nen dung ([GitHub DeepSpeech](https://github.com/MainRo/deepspeech-server/issues/41)). **Picovoice** ngung free tier tu 30/06/2026, chi con 7-day trial ([Hacker News](https://news.ycombinator.com/item?id=48248969)).

## Pipeline implementation: MediaRecorder den STT chi can vai chuc dong code

Toan bo pipeline tu thu am den nhan dien chi gom 3 buoc. **Buoc 1**: dung MediaRecorder voi `audio/webm;codecs=opus` -- format nay duoc **tat ca browser hien dai ho tro** ke ca Safari 18.4+ ([MDN MediaRecorder](https://developer.mozilla.org/en-US/docs/Web/API/MediaRecorder/MediaRecorder)). Luon dung `MediaRecorder.isTypeSupported()` de detect format thay vi hardcode, va fallback sang `audio/mp4` cho Safari cu ([BuildWithMatija](https://www.buildwithmatija.com/blog/iphone-safari-mediarecorder-audio-recording-transcription)). Set `channelCount: 1` (mono) va `noiseSuppression: true` de giam kich thuoc file va tang do chinh xac.

**Buoc 2**: detect im lang tu dong bang Web Audio API `AnalyserNode`. Tinh RMS volume moi ~50ms, khi RMS < 0.01 trong 1.5 giay lien tuc thi tu dong dung thu am ([Pavitra Golchha Blog](https://pavi2410.com/blog/detect-silence-using-web-audio/)). Dieu nay tao trai nghiem tu nhien: nguoi dung nhan nut, noi, va app tu dong dung khi ho ngung noi. Volume bar animation la **bat buoc** -- khong co no, nguoi dung se tuong app bi dong.

**Buoc 3**: gui audio blob den Cloudflare Worker qua `fetch()` voi FormData. Worker goi Whisper va tra ve text. Toan bo round-trip cho clip 5 giay mat 1-3 giay. Dung "optimistic UI" -- hien "Dang xu ly..." ngay khi dung thu am, truoc khi co ket qua tu server. Tren iOS Safari, **bat buoc** phai co user gesture (tap) de bat `getUserMedia` -- khong the tu dong thu am khi the hien ra.

## Conclusion

Chien luoc toi uu cho flashcard app tren GitHub Pages la **hai tang**: dung Web Speech API lam primary (zero cost, zero setup, instant results tren Chrome/Edge), va deploy mot Cloudflare Worker voi Whisper lam fallback cho browser khong ho tro hoac khi can do chinh xac cao hon. Tong chi phi: $0. Tong thoi gian setup: duoi 1 gio. Neu trong tuong lai can offline/privacy, transformers.js voi whisper-tiny.en la upgrade path ro rang -- chi can them ~40MB download lan dau va chuyen xu ly sang client. Cac giai phap cloud khac (Groq, Deepgram, Google, Azure) khong dang xem xet cho use case nay vi chung them phuc tap ma khong giai quyet van de nao ma Cloudflare Workers AI chua lam tot hon.
